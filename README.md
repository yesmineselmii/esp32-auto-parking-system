# ESP32 auto parking system
A small embedded systems project exploring how a vehicle can park automatically using an ESP32, ultrasonic sensors, and motor control.

The system measures distances around the vehicle, detects a suitable parking space, and controls the motors to perform the parking maneuver.

### Built With:
- **ESP32** — main controller
- **Ultrasonic sensors** — distance detection
- **L298N motor driver** — motor control
- **Arduino IDE** — programming and uploading the code

### How to use :
1. Open `robot.ino` in the Arduino IDE.
2. Connect your ESP32 and configure the board and port.
3. Check the wiring and pin assignments.
4. Upload the code and test the system in a safe, open area.
